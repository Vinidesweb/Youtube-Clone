# YouTube Clone

Clone do YouTube feito com React e TypeScript.

## Funcionalidades
- Login e cadastro
- Menu lateral que abre e fecha (estado global com Context API)
- Home com os vídeos cadastrados e pesquisa
- Envio de vídeo por link do YouTube
- Página "Seus vídeos"
- Layout responsivo (computador e celular)

## Tecnologias
React, TypeScript, styled-components, React Router, Axios

## Como rodar
1. `npm install`
2. `npm start`

Por padrão, o front usa o back em `http://localhost:4000`. Para apontar
para outro endereço, defina `REACT_APP_API_URL` no ambiente.
